無網格邊界積分法（BIQM）與 Motz 奇異點問題

探討二維穩態熱傳導（Laplace 方程式）在混合邊界條件交界處產生之 Motz 奇異點問題。透過無網格邊界積分求積法（BIQM）直接於邊界配置求積點，結合奇異函數解析分離與影響矩陣分塊求解未知廣義位移向量 $U_u$。

一、物理問題與控制方程式

考慮二維矩形計算域 $\Omega = (-1, 1) \times (0, 1)\,\text{m}^2$ 內之無熱源穩態熱傳導問題，其溫度場 $u(x,y)$ 滿足拉普拉斯控制方程式（Laplace Equation）：

$$\nabla^2 u(x,y) = \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0, \qquad (x,y) \in \Omega$$

在底邊 $y = 0$ 處，左側（$-1 < x < 0$）為絕熱 Neumann 邊界（$\partial u / \partial n = 0$），右側（$0 < x < 1$）為固定零溫 Dirichlet 邊界（$u = 0$）。兩類邊界在原點 $(0,0)$ 交會形成強奇異點，其局部極座標 $(r, \theta)$ 漸近解析解為：

$$u(r, \theta) = \sum_{n=0}^{\infty} a_n r^{n + \frac{1}{2}} \cos\left(\left(n + \frac{1}{2}\right)\theta\right)$$

利用邊界積分方程式（BIE）與基本解 $G(\mathbf{x}, \mathbf{y}) = -\frac{1}{2\pi} \ln \|\mathbf{x} - \mathbf{y}\|$ 離散後，依未知邊界廣義位移向量 $U_u$ 與已知邊界條件向量 $U_k$ 進行系統影響矩陣 $K_S$ 分塊：

$$\begin{bmatrix} K_{S,uu} & K_{S,uk} \\ K_{S,ku} & K_{S,kk} \end{bmatrix} \begin{Bmatrix} U_u \\ U_k \end{Bmatrix} = \begin{Bmatrix} F_u \\ F_k \end{Bmatrix} \implies K_{S,uu} U_u = F_u - K_{S,uk} U_k$$

二、符號定義表

變數符號 SI 單位 物理意義與數值定義
$K_S$ $\text{m}^{-1}, \text{無因次}$ 邊界積分求積系統影響矩陣（System Influence / Stiffness Matrix）
$U_u$ $\text{K}, \text{K/m}$ 邊界上未知廣義場量向量（含未知溫度、法向熱通量及奇異係數 $a_n$）
$U_k$ $\text{K}, \text{K/m}$ 邊界上已知 Dirichlet 或 Neumann 給定邊界條件向量
$G(\mathbf{x}, \mathbf{y})$ 無因次 二維拉普拉斯基本解（Fundamental Solution），$\mathbf{x}$ 為場點、$\mathbf{y}$ 為源點
$r, \theta$ $\text{m}, \text{rad}$ 以奇異點 $(0,0)$ 為原點之極座標半徑與極角
$a_0, a_1, \dots$ $\text{K/m}^{n+0.5}$ Motz 奇異點級數展開之應力／通量強度係數（領頭項 $a_0 \approx 401.1625$）

三、數值求解步驟

  1. 無網格邊界求積點配置：沿矩形四條邊界依高斯-勒讓德（Gauss-Legendre）求積權重配置邊界節點，無需生成元素網格與拓撲連接表。
  2. 奇異點函數分離（Singularity Subtraction）：將總場量拆解為光滑規則部分與前 $M$ 項 Motz 奇異級數項 $u = u_{\text{reg}} + \sum_{n=0}^{M-1} a_n \psi_n(r,\theta)$，使 $u_{\text{reg}}$ 在原點附近保持平滑。
  3. 組裝系統矩陣 $K_S$ 與奇異積分處理：計算基本解 $G(\mathbf{x},\mathbf{y})$ 與其法向導數 $\partial G / \partial n$，對角線弱奇異項採用解析積分或去奇異化技巧（Desingularization）精確求值。
  4. 施加邊界條件並求解 $U_u$：將已知邊界向量 $U_k$ 移項至右端項，透過奇異值分解（SVD）或最小二乘法求解超定方程組，同時獲得邊界未知場量與領頭奇異係數 $a_0$。
  5. 域內場量重構：利用已求得之 $U_u$ 與 $U_k$ 代回邊界積分恆等式，計算計算域 $\Omega$ 內部任意測點之溫度與熱通量分布。

四、MATLAB / Python 實作

以下 Python 範例展示如何建立二維拉普拉斯基本解核函數、配置邊界求積點並組裝系統影響矩陣 $K_S$ 求解未知邊界向量 $U_u$：

biqm_motz_solver.py (Python 3) 
import numpy as np

def generate_boundary_points(n_per_edge=20):
    """在 [-1, 1] x [0, 1] 矩形邊界配置均勻求積點與外法線向量 (SI 單位: m)"""
    s = np.linspace(-1.0, 1.0, n_per_edge, endpoint=False) + 1.0 / n_per_edge
    # 底邊 y = 0 (-1 < x < 1)
    x_bot, y_bot = s, np.zeros_like(s)
    nx_bot, ny_bot = np.zeros_like(s), -np.ones_like(s)
    
    # 右邊 x = 1 (0 < y < 1)
    y_right = (s + 1.0) * 0.5
    x_right = np.ones_like(y_right)
    nx_right, ny_right = np.ones_like(y_right), np.zeros_like(y_right)
    
    # 頂邊 y = 1 (1 > x > -1)
    x_top, y_top = -s, np.ones_like(s)
    nx_top, ny_top = np.zeros_like(s), np.ones_like(s)
    
    # 左邊 x = -1 (1 > y > 0)
    y_left = (1.0 - s) * 0.5
    x_left = -np.ones_like(y_left)
    nx_left, ny_left = -np.ones_like(y_left), np.zeros_like(y_left)
    
    pts = np.vstack([
        np.column_stack([x_bot, y_bot]),
        np.column_stack([x_right, y_right]),
        np.column_stack([x_top, y_top]),
        np.column_stack([x_left, y_left])
    ])
    normals = np.vstack([
        np.column_stack([nx_bot, ny_bot]),
        np.column_stack([nx_right, ny_right]),
        np.column_stack([nx_top, ny_top]),
        np.column_stack([nx_left, ny_left])
    ])
    return pts, normals

def assemble_system_matrix_KS(pts, normals, ds):
    """組裝無網格邊界積分求積系統矩陣 K_S"""
    N = len(pts)
    K_S_single = np.zeros((N, N))
    K_S_double = np.zeros((N, N))
    
    for i in range(N):
        for j in range(N):
            if i == j:
                # 對角線主值與自作用解析近似 (避免 ln(0) 奇異)
                K_S_single[i, j] = -(ds / (2.0 * np.pi)) * (np.log(ds / 2.0) - 1.0)
                K_S_double[i, j] = 0.5
            else:
                rx = pts[i, 0] - pts[j, 0]
                ry = pts[i, 1] - pts[j, 1]
                r2 = rx**2 + ry**2
                r = np.sqrt(r2)
                K_S_single[i, j] = -(1.0 / (2.0 * np.pi)) * np.log(r) * ds
                rn = rx * normals[j, 0] + ry * normals[j, 1]
                K_S_double[i, j] = -(rn / (2.0 * np.pi * r2)) * ds
    return K_S_single, K_S_double

# 執行 BIQM 矩陣組裝與未知向量 U_u 測試求解
pts, normals = generate_boundary_points(n_per_edge=16)
ds = 2.0 / 16.0
G_mat, H_mat = assemble_system_matrix_KS(pts, normals, ds)

# 已知邊界條件向量 U_k (右邊 x=1 給定 u = 500 K，其餘簡化示意)
U_k = np.zeros(len(pts))
U_k[16:32] = 500.0

# 求解未知邊界通量向量 U_u (K_S_uu * U_u = H_mat * U_k)
K_S_uu = G_mat
rhs = H_mat @ U_k
U_u = np.linalg.solve(K_S_uu, rhs)

print(f"系統影響矩陣 K_S 維度 : {K_S_uu.shape}")
print(f"未知向量 U_u 最大通量 : {np.max(np.abs(U_u)):.4f} K/m")

五、常見數值陷阱與除錯筆記

⚠️ 邊界積分法與 Motz 問題常見數值陷阱
  • 退化尺度（Degenerate Scale）導致系統矩陣奇異：二維拉普拉斯問題使用單層位勢基本解 $G(\mathbf{x},\mathbf{y}) = -\frac{1}{2\pi}\ln r$ 時，若計算域幾何特徵尺寸恰好落在外接圓半徑 $R = 1\,\text{m}$ 的退化尺度上，系統矩陣 $K_S$ 的條件數（Condition Number）會急劇惡化甚至不可逆。實作時應進行座標無因次化縮放或加入額外約束條件。
  • 未分離奇異點導致原點附近震盪：Motz 問題在 $(0,0)$ 處的法向通量具有 $r^{-1/2}$ 階無窮大奇異性，若僅加密邊界求積點而不加入奇異函數 $r^{n+0.5}\cos((n+0.5)\theta)$ 進行解析分離，數值解會在交界點附近產生劇烈 Gibbs 震盪且無法收斂。
  • 近邊界層效應（Near-Boundary Layer Effect）：當域內測點 $\mathbf{x}$ 非常靠近邊界源點 $\mathbf{y}$ 時，核函數呈現近奇異（Nearly Singular）變化，直接使用標準求積會產生大幅誤差，需改採非線性座標變換或自適應細分求積。
